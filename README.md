# CST2335 Lab 5

Android Studio project for the SQLite todo-list lab.

## Open and run
1. Extract this folder.
2. Open the `CST2335 Lab5` folder in Android Studio.
3. Allow Gradle sync to finish.
4. Run the app on an emulator or Android device.
5. Long-press a todo to delete it.
6. Use Logcat with the tag `Lab5Cursor` to view cursor details.

The app saves todos and urgency in SQLite and provides English and French string resources.

## Git branch
Create the requested branch in Android Studio: Git > Branches > New Branch > `lab_5`.
